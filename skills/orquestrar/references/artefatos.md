# Artefatos

O artefato é como a pessoa enxerga, controla e continua o trabalho. Um bloco de texto explicando o que foi feito tira esse controle.

## Escolha pelo uso

| A pessoa vai… | Artefato |
|---|---|
| ler, editar, enviar a alguém | documento |
| calcular, filtrar, atualizar números | planilha com fórmulas |
| apresentar | slides |
| entender um processo ou sistema | diagrama ou fluxograma |
| decidir entre opções | tabela comparativa com recomendação |
| continuar depois | pasta de projeto com arquivo de estado |
| rodar de novo sozinha | script ou automação com instruções |
| usar uma resposta e seguir a vida | a resposta, direto na conversa |

## Use o melhor que o ambiente produz

Se o ambiente gera arquivos, gere o arquivo. Se só conversa, entregue no formato mais fácil de levar adiante (tabela pronta para colar, texto já formatado) e diga qual seria o ideal.

## Por tipo de tarefa

| Tarefa | Artefato típico | Inclua |
|---|---|---|
| Jurídica | documento editável | aviso de rascunho para revisão profissional, lista de documentos, pontos a confirmar |
| Pesquisa | relatório com fontes | resposta no topo, fontes com link, o que não foi confirmado |
| Acadêmica | pasta de projeto | estado, roteiro de capítulos, referências conferidas |
| Comercial | documento ou slides + planilha | números com origem, próximo passo |
| Conteúdo | calendário + textos | o que precisa da aprovação da pessoa antes de publicar |
| Dados | planilha ou script | check dos totais, como repetir o processo |

## Recibo de fechamento

```
Entregue: <artefato e onde está>
Verificado: <o que foi conferido e como> · Não verificado: <o que ficou de fora>
Precisa da sua decisão: <se houver>
Próximo passo: <uma ação>
```

## Quando a tarefa se repete

Se a pessoa já fez esse tipo de tarefa antes, ou disser que vai fazer de novo, ofereça transformar o caminho numa skill dela: os critérios, a forma de trabalho e o artefato padrão. É assim que ela deixa de depender de lembrar o método.
