Plugin aberto para agentes de IA

Peça do seu jeito. O método fica com o agente.

O orquestrar faz o Claude, o ChatGPT e o Codex conduzirem qualquer tarefa como alguém experiente: entendem o que você quer, testam o que a ferramenta consegue, conferem antes de entregar e param para pedir sua aprovação antes do que não dá para desfazer.

O que muda

A mesma pergunta, com e sem método.

Caso real dos testes: “meu plano de saúde negou um exame que o médico pediu, preciso fazer uma carta ou petição pra eles. me ajuda?”

Sem método

  • Abre com cinco perguntas, nenhuma com resposta padrão.
  • Nada começa até você responder tudo.
  • Não diz como vai conferir as regras do plano.
  • Não deixa claro que o texto precisa de revisão antes de ser enviado.

Com orquestrar

  • Já começa o rascunho da carta e pergunta em cima dele.
  • No máximo três perguntas, cada uma com um padrão seguro.
  • Diz que vai conferir as regras aplicáveis antes de afirmar qualquer direito.
  • Entrega um documento editável e lembra que o envio é decisão sua.

Como funciona

Cinco fases, e uma triagem antes.

O agente percorre as fases sozinho. Você só aparece quando há uma decisão que é sua.

  1. 0

    Triagem

    Pergunta simples recebe resposta direta e completa. Sem cerimônia.

  2. 1

    Intenção

    Resultado, prazo e limites. Até três perguntas, cada uma com um padrão.

  3. 2

    Diagnóstico

    Testa o que a ferramenta consegue e escolhe a menor forma de trabalho.

  4. 3

    Execução

    Prepara tudo o que é reversível. Para antes de enviar, publicar ou apagar.

  5. 4

    Verificação

    Confere números, fontes e formatos. Quem produz não aprova.

  6. 5

    Entrega

    Um documento, planilha ou pasta, com um recibo curto do que foi feito.

Por que usar

Menos esforço seu, mais cuidado do agente.

Você não precisa saber escrever prompts

Peça como pediria a um colega. O agente descobre o que falta com poucas perguntas, cada uma com uma resposta padrão.

Nada irreversível sem você

E-mails, publicações, envios e exclusões ficam preparados e esperando o seu “pode enviar”.

Conferido antes de chegar

O agente diz o que verificou e o que ficou em aberto. Quem fez o trabalho não é quem aprova.

Algo para usar, não texto solto

O resultado vem como documento, planilha ou slides que você edita, e um recibo do que foi feito.

Instalar

Escolha o seu app.

Leva um minuto. Se os menus aparecerem em inglês, os nomes estão entre parênteses.

Claude

  1. Abra Personalizar (Customize) e vá à aba Plugins.
  2. Em Plugins pessoais (Personal plugins), clique em + e escolha Adicionar marketplace (Add marketplace).
  3. Escolha adicionar a partir de um repositório e cole:Syntelix-AI/orquestrar
  4. Instale o orquestrar na lista que aparecer.

Vale no Claude da web, no desktop e no Claude Code, que recebe os plugins da sua conta. Se você já tinha enviado o .zip da skill, remova a cópia avulsa em Personalizar → Skills, para não ficarem duas.

ChatGPT e Codex (desktop)

  1. Abra Plugins no app (no modo de trabalho ou na aba Codex).
  2. Clique em Adicionar marketplace.
  3. Em Origem, cole:Syntelix-AI/orquestrarEm Referência do Git, use main. Deixe Caminhos esparsos vazio.
  4. Instale o orquestrar na lista de plugins.

Se o seu app do ChatGPT não mostra a opção de adicionar marketplace, use a aba “Só a skill”: o envio de plugins próprios ao chat pode depender do seu plano.

Claude Code

  1. Num terminal com o Claude Code aberto, rode:/plugin marketplace add Syntelix-AI/orquestrar
  2. Depois:/plugin install orquestrar@orquestrar

Para conferir, rode /plugin e procure o orquestrar entre os instalados.

Codex CLI

  1. No terminal, rode:codex plugin marketplace add Syntelix-AI/orquestrar
  2. Depois:codex plugin add orquestrar@orquestrar

Comece uma sessão nova do Codex para a skill aparecer. Testado no Codex CLI 0.169.

Só a skill (.zip)

  1. Baixe o arquivo:Baixar orquestrar-skill.zip
  2. No Claude: Personalizar → Skills → + → Enviar uma skill (Upload a skill).
  3. No ChatGPT: Skills → Criar → Enviar do computador. No ChatGPT, as skills da web e do desktop não sincronizam: envie nos dois se usar os dois.

Assim você instala só a skill, sem catálogo. Atualizações não chegam sozinhas: baixe de novo quando sair uma versão.

Perguntas

Antes de instalar.

É seguro?

O plugin é só texto: instruções que o agente lê. Ele não roda programas, não instala nada no seu computador e não pede acesso a contas. O agente continua com as mesmas permissões de antes, e a skill manda que ele pare e peça sua aprovação antes de enviar, publicar, pagar ou apagar.

Quanto custa?

Nada. O orquestrar é aberto, sob a licença MIT. Ele usa o plano que você já tem em cada app; a disponibilidade de plugins e skills depende desse plano.

Meu assistente vai ficar lento ou cheio de perguntas?

Não deveria. Perguntas simples continuam com resposta direta, e os testes têm uma armadilha só para isso. Em tarefas maiores, são no máximo três perguntas, cada uma com uma resposta padrão: você pode só dizer “pode seguir”.

Funciona em outras línguas?

A skill está escrita em português, mas o agente responde na língua em que você escreve.

Como eu removo?

Na mesma tela de plugins do app, desinstale o orquestrar. No terminal: /plugin uninstall orquestrar@orquestrar (Claude Code) ou codex plugin remove orquestrar@orquestrar (Codex).
