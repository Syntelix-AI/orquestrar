What changes

Same question, with and without a method.

A real test case: “my health plan denied a test my doctor ordered, I need to write them a letter or a petition. can you help?”

Without a method

  • Opens with five questions, none with a default answer.
  • Nothing starts until you answer them all.
  • Doesn't say how it will check the plan's rules.
  • Doesn't make clear the text needs review before it's sent.

With orquestrar

  • Starts drafting the letter and asks on top of the draft.
  • Three questions at most, each with a safe default.
  • Says it will check the applicable rules before claiming any right.
  • Delivers an editable document and reminds you that sending it is your call.

How it works

Five phases, and a triage first.

The agent goes through the phases on its own. You only come in when there's a decision that is yours.

  1. 0

    Triage

    A simple question gets a direct, complete answer. No ceremony.

  2. 1

    Intent

    Result, deadline and limits. Up to three questions, each with a default.

  3. 2

    Diagnosis

    Tests what the tool can do and picks the smallest way of working.

  4. 3

    Execution

    Prepares everything reversible. Stops before sending, publishing or deleting.

  5. 4

    Verification

    Checks numbers, sources and formats. Whoever produced it doesn't approve it.

  6. 5

    Delivery

    A document, spreadsheet or folder, with a short receipt of what was done.

Why use it

Less effort from you, more care from the agent.

No prompt writing needed

Ask as you'd ask a colleague. The agent finds what's missing with a few questions, each with a default answer.

Nothing irreversible without you

Emails, posts, submissions and deletions stay prepared and wait for your “send it”.

Checked before it reaches you

The agent says what it verified and what's still open. Whoever did the work isn't who approves it.

Something to use, not loose text

Results come as documents, spreadsheets or slides you can edit, plus a receipt of what was done.

Install

Pick your app.

It takes a minute.

Claude

  1. Open Customize and go to the Plugins tab.
  2. Under Personal plugins, click + and choose Add marketplace.
  3. Choose to add from a repository and paste:Syntelix-AI/orquestrar
  4. Install orquestrar from the list.

Works on Claude web, desktop and Claude Code, which receives your account's plugins. If you had already uploaded the skill's .zip, remove that copy under Customize → Skills so you don't have two.

ChatGPT and Codex (desktop)

  1. Open Plugins in the app (in work mode or in the Codex tab).
  2. Click Add marketplace.
  3. Under Source, paste:Syntelix-AI/orquestrarUnder Git ref, use main. Leave Sparse paths empty.
  4. Install orquestrar from the plugin list.

If your ChatGPT app doesn't show the option to add a marketplace, use the “Just the skill” tab: adding your own plugins to chat may depend on your plan.

Claude Code

  1. In a terminal with Claude Code open, run:/plugin marketplace add Syntelix-AI/orquestrar
  2. Then:/plugin install orquestrar@orquestrar

To check, run /plugin and look for orquestrar among installed plugins.

Codex CLI

  1. In a terminal, run:codex plugin marketplace add Syntelix-AI/orquestrar
  2. Then:codex plugin add orquestrar@orquestrar

Start a new Codex session for the skill to show up. Tested on Codex CLI 0.169.

Just the skill (.zip)

  1. Download the file:Download orquestrar-skill.zip
  2. In Claude: Customize → Skills → + → Upload a skill.
  3. In ChatGPT: Skills → Create → Upload from your computer. ChatGPT's web and desktop skills don't sync: upload to both if you use both.

This installs only the skill, with no catalog. Updates won't arrive on their own: download again when a new version ships.

Questions

Before you install.

Is it safe?

The plugin is just text: instructions the agent reads. It doesn't run programs, install anything on your computer or ask for account access. The agent keeps the same permissions as before, and the skill tells it to stop and ask for your approval before sending, publishing, paying or deleting.

How much does it cost?

Nothing. orquestrar is open source under the MIT license. It uses the plan you already have in each app; plugin and skill availability depends on that plan.

Will my assistant get slow or ask too many questions?

It shouldn't. Simple questions still get direct answers, and the tests include a trap just for that. For bigger tasks, it asks three questions at most, each with a default: you can just say “go ahead”.

Does it work in other languages?

The skill is written in Portuguese, but the agent replies in the language you write in.

How do I remove it?

Uninstall orquestrar on the same plugins screen in your app. In a terminal: /plugin uninstall orquestrar@orquestrar (Claude Code) or codex plugin remove orquestrar@orquestrar (Codex).
